# Phonton Desktop v0.4.0 — Local workbench

Desktop now opens into a local workbench. No account, no sign-in, no network
calls for inference: everything runs against a model on your machine and is
checked by your own tests.

## Local models

- Install a pinned, hash-checked Ollama runtime that Phonton starts and
  verifies, or connect your own on a loopback port.
- Download a coding model, with fit estimated from your RAM and GPU before
  you download.
- Calibrate it: each edit format is probed on this machine and shown as pass
  or fail. Phonton only asks the model for formats it passed.

## A goal, checked

- Open a repository and describe the change. The plan shows the files, the
  exact check commands, the model and the budget before any model call.
- The baseline runs first. Each candidate is applied to an isolated copy and
  your checks run; a failing candidate goes back to the model with the
  failing output. Every attempt, its diff, the source the model saw and the
  check logs stay inspectable.
- Apply a verified candidate with original-byte backups, and restore it later
  if you change your mind.

## Platforms

- **Windows x64:** the installer includes the Phonton engine (CLI 0.24.0).
- **macOS and Linux:** install the CLI first (`npm install -g phonton-cli`);
  Desktop starts it.

The previous online shell is still available from Settings.
