# Phonton Desktop v0.5.1 — CLI 0.25.0 engine

Desktop now ships with the CLI 0.25.0 engine: current local models, honest
fit estimates and jest verification.

## Changes

- Local models lists current local coding models and marks one to try first
  by total memory (the largest GPU, or half of RAM when that is larger):
  `qwen3.5:4b` for 4-6 GB, `qwen3.5:9b` or `gemma4:12b` for 6-16 GB,
  `gpt-oss:20b` for 16-24 GB, and `qwen3.6:35b-a3b` or `qwen3.6:27b` for
  24 GB and up. Under 4 GB, or without a memory reading, nothing is suggested.
  The `qwen2.5-coder` entries are gone.
- Fit estimates read the KV cache size from the installed model instead of a
  flat reserve, so `qwen3.5:4b` calibrates above 4096 tokens on a 6 GB GPU. A
  model that fits the largest GPU plus available RAM is admitted as partly
  offloaded.
- Local goal runs can verify jest projects. Each check installs the project's
  own jest offline from its lockfile, and a pass needs at least one passing
  test and coverage of every edited file.
- When the npm registry is unreachable, Desktop's CLI install falls back to
  0.25.0 instead of 0.21.0.

## Installing

The installers are not code-signed yet. Windows SmartScreen and macOS
Gatekeeper warn on first launch; the README's "First launch of an unsigned
build" section has the steps. Check downloads against `SHA256SUMS.txt`.

## Engine

- **Windows x64:** the installer includes the Phonton engine (CLI 0.25.0).
- **macOS and Linux:** install the CLI first (`npm install -g phonton-cli`);
  Desktop starts it.
