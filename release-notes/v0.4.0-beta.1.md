# Phonton Desktop 0.4.0-beta.1

Local beta candidate; public engine source is pinned, with installed-app and
signed distribution evidence still required before release.

- [changed] A calmer workbench with readable interface text, a compact header,
  an immediately visible goal composer and expandable history and machine details.
- [changed] Model selection foregrounds installed models, calibration and fit.
- [fixed] Partial checks, API cost and runtime origin use evidence-specific labels.
- [fixed] Windows release packaging resolves Tauri's release build profile correctly.
- [fixed] Release metadata rejects mismatched versions and keeps beta builds out
  of stable update discovery.

Windows x64 Preview packages contain a hash-checked 0.22.0 local engine. macOS and
Linux native packages and signed update delivery need their own release evidence.
