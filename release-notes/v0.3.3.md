# Phonton Desktop v0.3.3

## Economics strip

Persistent strip for task, models, cost, verification, and saved vs frontier. Idle copy: "Run a goal to fill cost and checks." Empty numbers stay as hyphens.

## Receipt

The strip is the cost metric. The side panel lists files and checks only. The Receipt tab keeps the full packet.

## Setup

Provider key step before Finish. Keys stay in local CLI config. `phonton doctor --provider` is the gate.

## Requires

**phonton-cli v0.21.1+** for `cost_receipt` on serve. v0.21.0 still connects; older CLIs cannot.
