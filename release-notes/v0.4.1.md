# Phonton Desktop v0.4.1 — No account anywhere

Phonton is free and runs on your machine, so Desktop no longer asks for a
phonton.dev account anywhere.

## Changes

- The provider-key workbench (Settings → General → Provider-key workbench
  setup) no longer has a sign-in step. Setup is theme, engine, provider key.
- Settings opens on Provider. The Account page, which offered a cloud-sync
  token for a sync service that does not exist, is gone, as are the plan
  badge and the Cloud pricing link in the header.
- Numbers in the workbench, the local models page and token counts use
  tabular figures, so columns of sizes and counts line up.
- If Desktop cannot read its own version, Settings says "unknown" instead of
  showing nothing.

## Engine

- **Windows x64:** the installer includes the Phonton engine (CLI 0.24.1).
- **macOS and Linux:** install the CLI first (`npm install -g phonton-cli`);
  Desktop starts it.
