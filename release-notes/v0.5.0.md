# Phonton Desktop v0.5.0 — ASCII workbench and themes

The local workbench gets one terminal-style design, a sidebar, a commands
menu and a theme editor that imports your terminal palette.

## Changes

- A sidebar holds Goal, Runs, Local models and Settings; on narrow windows it
  becomes a top bar. Settings opens inside the workbench instead of replacing
  it.
- Commands (Ctrl+K) reaches navigation, open repository, review plan, new
  goal, cancel, reconnect, themes and recent runs from the keyboard.
  Ctrl+Enter in the goal box reviews the plan.
- The Goal page starts with live engine, model, memory, GPU and storage
  readings, with recent runs beside the composer. A Runs page lists saved runs
  and opens one by run ID.
- One ASCII design language across the workbench, setup, Local models and
  Settings: the ANSI Shadow logo, framed panels, state glyphs (✓ ✗ ◇ ▶), a
  spinner and text progress bars. Motion runs once on a state change and stops
  under reduced motion.
- Settings → Appearance edits the theme: accent, background, foreground and the
  remaining palette colors, density, and font, with live contrast ratios.
  Presets are Nebula (default), Graphite (formerly Cursor Dark), Light and High
  contrast.
- Import a palette from base16 YAML, iTerm2 `.itermcolors`, Ghostty config or
  Windows Terminal JSON, and export the current theme as JSON.
- Themes now reach the local workbench and Local models, which kept hardcoded
  colors before.

## Fixes

- The provider-key shell's sidebar no longer covers its header, and the header
  and Settings fit at 390px.
- The sidebar showed a stale v0.3.4; it now shows the build version.
- Setup's finish step showed a check mark for steps that were not ready.

## Installing

The installers are not code-signed yet. Windows SmartScreen and macOS
Gatekeeper warn on first launch; the README's "First launch of an unsigned
build" section has the steps. Check downloads against `SHA256SUMS.txt`.

## Engine

- **Windows x64:** the installer includes the Phonton engine (CLI 0.24.1).
- **macOS and Linux:** install the CLI first (`npm install -g phonton-cli`);
  Desktop starts it.
