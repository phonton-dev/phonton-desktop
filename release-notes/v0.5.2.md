# Phonton Desktop v0.5.2 — CLI 0.25.1 engine

Desktop now ships with the CLI 0.25.1 engine, so local goal runs keep working
on a busy laptop.

## Changes

- A local model that is already loaded entirely in VRAM keeps working when
  other apps take host memory. CLI 0.25.0 stopped a local goal run with
  `resource_pressure` once available RAM fell below 1.5 GiB, even with the
  model loaded on the GPU. On a 16 GB laptop with a browser and chat apps open,
  running a project's checks between model calls was enough to trigger that.
  A call to a fully VRAM-resident model now needs 512 MiB free. Cold loads,
  partly offloaded models and unknown memory readings keep the full reserve.
- When the npm registry is unreachable, Desktop's CLI install falls back to
  0.25.1.

## Installing

The installers are not code-signed yet. Windows SmartScreen and macOS
Gatekeeper warn on first launch; the README's "First launch of an unsigned
build" section has the steps. Check downloads against `SHA256SUMS.txt`.

## Engine

- **Windows x64:** the installer includes the Phonton engine (CLI 0.25.1).
- **macOS and Linux:** install the CLI first (`npm install -g phonton-cli`);
  Desktop starts it.
